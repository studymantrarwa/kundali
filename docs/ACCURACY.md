# Accuracy / licensing

Swiss Ephemeris provides astronomical ephemeris calculations. This is substantially different from a random/fake calculator, but the project should still be validated against your chosen reference charts.

This package uses Lahiri sidereal mode and mean Rahu. D9 mapping and displayed dasha dates should be cross-checked against your desired Vedic astrology convention before commercial release.

Google Time Zone API has limitations around historical timezone changes. For India this is normally straightforward; worldwide historical dates require additional validation.

Review Swiss Ephemeris licensing before commercial/closed-source deployment.
